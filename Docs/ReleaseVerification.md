# 0.7.3 正式版の検証と配布

0.7.1 は目のレイヤー焼き込み、焼き込み前の画像による強い発光、FaceEmo の登録済み表情、ペット・ギミックの明示的な除外を修正するリリースです。
0.7.2 は、0.7.1に同梱したEditorテストのNUnit API呼び出しによるCS1503を修正します。
0.7.3 は静止UV0のデカール等を自動焼き込みの対象にし、実際に問題のある設定を事前に一覧表示します。明示的に選んだ場合だけ、該当する装飾レイヤーを出力用コピーから省略して再試行します。
顔の位置・大きさを身体の骨格から計算する変更は VR Vlog アプリ側の修正です。エクスポーターの更新だけでは、インストール済みアプリの計算は変わりません。

## 公開前の確認

1. 最新の PR コミットをレビューし、CI の Validate と VPM リスト生成テストを通します。
   `Tools/run-bake-tests.ps1` は実際の事前判定と省略処理をテストダブルで実行します。GPU処理を模擬せず、Unityの描画テストとは区別します。
2. Unity 2022.3.62f3、UniVRM 0.131.0、lilToon 2.3.4 でパッケージ全体をコンパイルします。`Tests/Editor` を Gamma / Linear の両方で実行し、失敗・スキップがない NUnit XML と Editor ログを保存します。GPU ベイクを含むため `-nographics` は使用しません。
3. 元アバターを別名で書き出します。未ベイクのメインカラー 2nd/3rd、ベイク済みの目、FaceEmo の別シーンオブジェクトからの登録を確認します。元のマテリアル・メッシュ・設定に変更がないことも確認します。
4. ペットを残した版と、書き出し設定で除外した版を作ります。除外版は読み込み可能で、身体・衣装・表情・揺れ物の参照が欠けていないことを確認します。
5. 修正版アプリで両方を読み込み、正面・顔追跡中・再読み込み後の頭の位置とサイズを比較します。目の色は元の Unity 表示と見比べ、FaceEmo の登録名と組み合わせた表情を確認します。
6. UV0のデカール範囲、コピー、MSDF文字を比較します。不対応の複数設定を入れ、元マテリアルの選択、詳細コピー、省略への明示同意、共有マテリアルの適用範囲、保存先を変更してからの再試行を確認します。`.unity` を出力先に指定した場合は解析前に停止することを確認します。

ホスト上の C# テストは JSON・数値処理の検証です。Unity のコンパイル、GPU の色空間、ALCOM の導入、iPhone の描画を実行済みと扱うことはできません。実行結果には対象コミットと依存バージョンを記録してください。コードを変更した場合は、影響する検証と最新コミットのレビューをやり直します。

## ALCOM 向けの公開

レビュー済み PR を main へマージします。GitHub Actions の **Release VPM Packages** を main から実行し、Exporter `0.7.3` / UniVRM `0.131.0` を指定します。ワークフローはバージョン、ホストテスト、タグ重複を確認し、パッケージを添付した `v0.7.3` リリースを作成します。その後 VPM リスト生成・GitHub Pages 配備が実行されます。

次を公開結果として確認します。

- リリースのエクスポーター ZIP にある `package.json` が `0.7.3` で、対応する UniVRM パッケージが添付されている。
- [VPM リポジトリ](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/index.json) に `0.7.3` があり、添付 ZIP の URL と SHA-256 が一致している。
- ALCOM のリポジトリ更新で `0.7.3` が表示され、既存版からの更新と新規プロジェクトへの導入が成功する。

私有アバター、参考画像、元 Unity プロジェクト、アプリの非公開コードをリリースへ添付しないでください。
