# VR Vlog lilToon VRM Exporter

**お気に入りのアバターをVR Vlogで使う。**

lilToonのアバターを、VR Vlogで使う **VRM 1.0** に書き出すUnity Editor用パッケージです。対応する見た目、顔・体形の調整、登録済みの表情を保存します。

[インストールページ](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/) · [最新リリース](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/releases/latest) · [変更履歴](CHANGELOG.md)

以下は0.9.0の利用案内です。公開中のパッケージは[最新リリース](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/releases/latest)で確認できます。通常の導入には、インストールページで案内するバージョンを使ってください。

## 必要な環境

| 項目 | 条件 |
| --- | --- |
| Unity | 2022.3。VRChatプロジェクトではVCC・ALCOMが案内する対応版を使用 |
| lilToon | **2.3.4必須**。元のアバターと一緒に事前に導入 |
| UniVRM | 0.131.x。VCC・ALCOMでは0.131.0を依存パッケージとして導入 |
| 対応マテリアル | lilToon / lilToon Lite / lilToon Multiの対応設定 |
| 着せ替え | Modular Avatarと依存パッケージを事前に導入。現在のMA表示の反映はMA 1.18.7 / NDMF 1.14.8で検証 |
| 出力 | VRM 1.0。他のVRMビューアーでは標準MToonによる互換表示を使用 |

Unity 2022.3.22f1で検証しています。別のUnity系列・未検証のパッケージの組み合わせでの動作は保証していません。

## インストール

1. [インストールページ](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/)の「VCC / ALCOMに追加」を押します。
2. VCC・ALCOMで使いたいUnityプロジェクトのパッケージ管理画面を開きます。
3. **VR Vlog lilToon VRM Exporter** をインストールします。必要なUniVRMも依存関係として導入されます。

ボタンで開かない場合は、使いたいアプリのリポジトリ追加画面に次のURLを貼り付けてください。

```text
https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/index.json
```

更新前にはUnityプロジェクトをバックアップしてください。

### ZIPで手動導入する

1. [インストールページ](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/)の「ZIPで導入」を開き、エクスポーターとUniVRMの3つのZIPをダウンロードします。
2. 各ZIPをプロジェクトの `Packages` 内の別々のフォルダーへ展開し、それぞれのフォルダー直下に `package.json` がある状態にします。
3. Unityでパッケージの読み込みが終わるのを待ちます。

展開先をプロジェクトの外に置く場合は、Unity Package Managerの **Add package from disk** から、UniGLTF・VRM・エクスポーターの順に各 `package.json` を選択します。登録したフォルダーは移動・削除しないでください。`Assets` や `Packages` に導入済みの同じUniVRMパッケージと重複させないでください。

## 使い方

1. Unityでアバターを開き、書き出す衣装・オブジェクト・Rendererを有効にします。アバターの最上位と親も有効にしてください。
2. メニューの **VR Vlog → lilToon VRM 1.0を書き出す** を開きます。
3. **① アバター（必須）** にHierarchyのアバター最上位を指定し、**② 作者名（必須）** にVRMへ記録する作者名を入力します。VRM名にはオブジェクト名を使います。
4. 必要に応じて「書き出し設定」で発光の抑制や、除外するペット・ギミックを指定します。
5. **③ 保存先を選んでVRMを書き出す** を押し、保存先を指定します。
6. できた `.vrm` をiPhoneへ送り、VR Vlogで読み込みます。見た目・まばたき・口・表情・髪と衣装の追従を確認してください。

元のアバター・メッシュ・マテリアル・画像の設定は変更しません。髪や衣装には、元のプロジェクトでMA Bone Proxy / Merge Armatureなどの接続設定が必要です。配置や名前だけから頭への接続を作る機能ではありません。

### 補助ギミックの自動除外

「書き出し設定」の **補助ギミックを自動除外** は初期状態でオンです。確認済みの撫でシステムや、作者が代替表示で非表示に指定した未対応シェーダー（`VRCFallback=Hidden`）だけを対象にします。名前・黒い色・球形・ContactやPhysBoneの存在だけでは除外しません。

検出一覧の **この対象は含める** で個別に保持できます。通常材質との混在、材質の欠損、識別できないものは自動除外せず、理由を表示します。必要なら **手動の除外一覧に追加** してください。手動除外は「含める」より優先します。アバターを変更すると個別指定をリセットします。

衣装や表情の処理後にも材質を確認し、出力用コピーの補助Rendererを省略します。システム全体に通常の表示物や外部から参照される骨がある場合は、必要なTransformと表示物を残します。完了画面の詳細で結果を確認できます。既存VRMへのデータ追加には適用されず、元アバターからの再出力が必要です。

## 対応範囲と制限

| 対象 | 動作・制限 |
| --- | --- |
| マテリアル | 色、影、発光、リム、MatCap、輪郭線などの対応設定を保存。描画方式や照明による差が残ります |
| アルファ・輪郭・発光 | 静的アルファマスクと対応する輪郭幅・発光の設定を保存。追加表示には対応版のVR Vlogが必要 |
| メインカラー2nd/3rd | 対応する静止レイヤー・色調補正・デカール・MSDF文字を画像に反映。自動変換できない設定は対象と理由を表示 |
| 画像 | 縦横比を保って長辺1024以下へ縮小。元の画像は変更しません |
| 顔・体形 | MAで調整した現在の体形と、対応するBlendShapeの調整値・表情を保存。対応するまばたき・口の表情を補います |
| メニュー表情 | 登録済みButton・Toggleの対応する固定BlendShape表情を、一項目につき一つの表情として保存 |
| ジェスチャー表情 | FX Controllerに登録された対応クリップが対象。動く表情の再生には対応版のVR Vlogが必要 |
| FaceEmo | 対象アバターに関連付けられた保存済みの登録内容が対象。VRChatの条件判定や連続操作全体は再現しません |
| 衣装・髪 | MAで調整した現在の表示・材質・Mesh Cutterと、対応する接続設定を反映。非表示の衣装は含まれません |
| 揺れ物・ギミック | VRChatのPhysBoneや任意のギミック全般をVRMへ変換する機能はありません。既存の対応するVRM揺れ物は保持します |
| 未対応 | ファー・屈折・宝石・テッセレーション・AudioLinkなどは近似または省略。マテリアル差し替え・表示切り替え・ボーン変形を伴う表情、Puppet、自動生成される一部のメニューは対象外 |
| 他のVRMビューアー | 標準MToonの互換表示を使用。追加の動く表情は静止した先頭の顔になります |

### iPhoneで読み込む

1. 書き出した `.vrm` ファイルをiPhoneの「ファイル」に保存します。
2. VR Vlogの設定に **実験的機能 → lilToon互換表示（モバイル）** がある版では、追加データを使う場合にオンにします。
3. **モデルを変更 → 端末のVRMを選ぶ** からファイルを選びます。設定を変更する前に読み込んでいた場合は、読み込み直してください。
4. 見た目・まばたき・口・表情を確認します。位置・サイズ・明るさなどは **モデルの見え方 → 内カメラで調整** から調整できます。

追加データの表示は、アプリの対応版と表示設定に依存します。オフの場合や追加データを適用できない場合は標準MToon表示になります。エクスポート成功だけで、アプリ内の見た目の一致を保証するものではありません。

0.9.0の追加データに未対応のアプリでは、標準MToon表示になります。アプリの更新内容を確認してください。

エクスポーターを更新しても、以前に書き出したVRMは変わりません。新たに対応した設定を反映するには、元のUnityアバターから再度書き出してください。

## 困ったとき

- **省略された設定を確認したい**：完了画面の「詳細を見る」、またはUnity Consoleの「VR Vlog 書き出し詳細」を確認してください。
- **発光や目の色が違う**：「目などの白飛びを抑える」「別画像の強い発光も抑える」は0.9.0では初期状態でオフです。オンにすると意図した発光も抑える場合があるため、必要な場合だけ使ってください。
- **レイヤーを変換できない**：画面の対象・設定・次の操作を確認してください。「表示されたレイヤーを省略して書き出す」は、その装飾を同じマテリアルの使用箇所すべてから省略します。見た目を残したい場合は省略せず、元の設定を確認してください。
- **髪や袖が追従しない**：元のプロジェクトでMAなどの接続設定とエラーを確認し、最新エクスポーターで再出力してください。既存VRMだけから元の接続設定を復元することはできません。
- **NDMFの処理で停止する**：表示されたプラグイン名・処理名と、該当するエラーを確認してください。

出力VRMには指定した作者名・モデル名のほか、モデルの形状・画像・表情名などが含まれます。素材の利用条件を確認してから書き出し・共有してください。
