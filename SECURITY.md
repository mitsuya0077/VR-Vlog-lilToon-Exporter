# セキュリティポリシー / Security policy

## 脆弱性の非公開報告

このエクスポーターの脆弱性は、[GitHubの非公開脆弱性報告](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/security/advisories/new)から管理者へ報告してください。GitHubアカウントでのログインが必要です。リポジトリの **Security → Advisories → Report a vulnerability** からも開けます。

脆弱性の再現手順や悪用条件を、公開Issue・Pull Request・公開コメントへ投稿しないでください。通常の不具合・改善提案は[公開Issue](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/issues/new/choose)で受け付けています。

可能な範囲で、次の情報を記載してください。

- エクスポーターのバージョンまたはコミットと、Unity・関連パッケージのバージョン
- 問題の概要、発生条件、影響を受ける処理と想定される影響
- 再現手順と、共有できる最小限のコードや入力例

非公開報告でも、認証情報・秘密鍵・購入したアバター・元プロジェクト・個人情報を含むログ全文は送らないでください。追加の資料が必要な場合は、非公開の報告内で共有方法を相談してください。修正や公表についても、その報告内で相談します。

## 対象バージョン

まず[最新の安定版](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/)で発生するか確認できると調査に役立ちます。旧版・ベータ版で見つかった問題も、該当バージョンを明記して報告できます。修正の対象バージョンと提供方法は、報告の内容に応じて判断します。

## Private vulnerability reports

Report vulnerabilities in this exporter through [GitHub private vulnerability reporting](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/security/advisories/new). Sign in with a GitHub account. The form is also available under **Security → Advisories → Report a vulnerability** in this repository.

Do not post vulnerability reproduction details or exploit conditions in public issues, pull requests or comments. Use [public issues](https://github.com/mitsuya0077/VR-Vlog-lilToon-Exporter/issues/new/choose) for ordinary bugs and improvement proposals.

Where possible, include:

- The exporter version or commit, and Unity and relevant package versions
- A summary, the conditions required, the affected functionality and potential impact
- Reproduction steps and minimal code or input examples that you can share

Even in a private report, do not send credentials, private keys, purchased avatars, complete original projects or full logs containing personal information. Discuss how to share any additional material, fixes and disclosure within the private report.

## Versions

Checking the [latest stable release](https://mitsuya0077.github.io/VR-Vlog-lilToon-Exporter/) can help investigation. Reports about older or beta versions are also welcome; specify the affected version. The version and delivery method of a fix will be determined based on the report.

## 管理者の通知 / Maintainer notifications

管理者は、このリポジトリの **Watch → Custom → Security alerts** を購読し、非公開報告を確認してください。メール通知の有無は各管理者の通知設定に依存します。[GitHubの通知設定の説明](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository#configuring-notifications-for-private-vulnerability-reporting)を参照してください。

Maintainers should subscribe to **Watch → Custom → Security alerts** for this repository and check private reports. Email delivery depends on each maintainer's notification preferences; see [GitHub's notification instructions](https://docs.github.com/en/code-security/how-tos/report-and-fix-vulnerabilities/configure-vulnerability-reporting/configure-for-a-repository#configuring-notifications-for-private-vulnerability-reporting).
