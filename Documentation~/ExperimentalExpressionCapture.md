# 表情・ポーズを指定して書き出す

このZIPは非公開の手元試験版です。正式公開は行っていません。

Unityの **VR Vlog → 表情・ポーズを指定して書き出す** を開きます。

1. Hierarchyからアバターを指定し、**表情ファイルを選ぶ**を押します。
2. **候補ファイル**で取り込みたい表情にチェックを入れ、**選んだ○件を追加**を押します。**表示中を選択**でまとめて選べます。候補名を押すと追加前に顔を確認できます。
3. 追加した表情の**確認**で顔を切り替えます。チェックを外した表情は保存しません。表情名は変更できます。
4. 作者名と従来のライセンス設定を確認し、**VRMを保存**を押します。
5. 保存完了欄の **QRコードでスマホに送る** → **アップロードしてQRを表示** を押し、QR受信対応のiPhone版VR Vlogの **モデルを変更 → PCから受け取る** で読み取ります。

候補はFaceEmoやアバターに登録されたControllerが実際に参照するファイルです。名前の推測で選びません。
候補が見つからない場合は、UnityのProjectで.animを複数選択して表情欄にドロップするか、ファイル欄で指定して追加できます。ALCOMに登録するのはExporter本体で、表情ファイルはUnityで指定します。

プレビューは画面上部に表示します。画像をドラッグすると向きを変え、ホイールで拡大できます。**元の顔**で基準に戻します。

## 収録する範囲

秒数の指定は不要です。表情はファイルの終端の値を固定の顔として保存します。最初から最後まで同じ顔の一般的な表情クリップはそのまま使え、無表情から変化するクリップは変化後の顔になります。終端が無表情に戻るクリップも終端を使うため、候補名を押して結果を確認してください。動く表情全体の再生は収録しません。

任意の全身ポーズは **全身ポーズを追加** を開き、別の枠に.animをドロップします。**ポーズを確認**で見られます。静止ポーズは先頭、動くポーズは先頭から最後までを既存のポーズ仕様で保存します。表情とポーズは別々に選べるデータとして同じVRMに同梱します。同時に呼び出すプリセット機能はありません。

## 選べない項目

- **追加済み**はすでに保存対象の一覧に入っています。
- **対応外**は候補名を押すと理由を表示します。直接追加した項目では**理由**を押します。部分的な取り込みで欠落を隠さず、保存対象には入りません。
- Playモード中は編集できません。
- 表情が0件、作者名が空欄の場合は保存できず、ボタンの近くに理由を表示します。

対応するのは書き出すSkinnedMeshRendererのBlendShapeです。材質・画像差し替え、顔ボーン、表示切替、Animation Event、曖昧なメッシュ統合や欠けた変形は未対応です。複数クリップの合成・共通FX設定が必要な顔は単一ファイルと異なる場合があります。
指定しない変形は毎回基準の顔から補い、直前の顔を引き継ぎません。最大64表情です。

手動調整、メニュー全体の自動取り込み、コピー再作成、記録設定の保存・読み込みはこの画面に表示しません。アバターを再指定する場合は**変更**を使います。保存済みVRMは残ります。

## QR転送

PCで暗号化したVRMをクラウドへ一時保存します。復号鍵はQRだけに含め、サービスへ送りません。PCとiPhoneのインターネット接続が必要で、同じWi-Fiは不要です。256 MiB以下、受取期限は転送作成から3分です。アップロード中も期限が進みます。QRは共有・撮影しないでください。Android配布版の受信は無効です。

転送は最後に保存したVRMを使います。編集した場合は再保存してください。保存ファイルの移動・上書きは検知して再保存を案内します。画面を閉じても元のVRMは消えません。通信エラーは停止した工程と原因を一度だけ表示します。
詳細は同梱の[QR転送ガイド](CloudTransfer.md)、検証範囲はZIP直下の検証結果.mdを参照してください。
