# 表情ファイルを指定して書き出す実験版

安定版0.11.14とは別に導入する、ALCOM用ユーザーパッケージ `0.11.14-expression-capture.3` です。
表情のAnimationClipを明示指定して、そのファイルが表す固定の顔を記録します。
FaceEmoやFX全体の再生・自動収録は必須ではありません。元アバターと元ファイルは編集しません。

## 導入

1. ALCOMで普段のアバタープロジェクトを複製し、複製側で試します。Unityを閉じてパッケージを入れ替えてください。
2. 導入ZIPを全部展開し、ALCOMの「パッケージ」→「ユーザーパッケージ」→「パッケージを登録」で、
   `com.vrvlog.liltoon-vrm-exporter` フォルダーを指定します。この中に `package.json` があります。
3. プレリリースを表示する設定をONにし、複製プロジェクトの「管理」で上記バージョンを選んで適用します。
   同じExporterをAssetsとPackagesへ重複導入しないでください。Unity Package Managerの「Add package from disk」でも導入できます。
4. Unityで **VR Vlog → 実験 → 表情を記録して書き出す** を開きます。

## 表情を試す

1. シーンのアバターを「アバター」欄へ入れ、作者名を入力し「アバターを読み込む」を押します。
   ライセンス設定は通常版と同じ欄です。元の規約に合わせて設定してください。
2. Unityの **Projectウィンドウ** から表情の `.anim` を「2. 表情ファイルを追加して試す」の枠へドロップします。複数選択もできます。
   「表情ファイル」欄でファイルを指定して「追加」する方法もあります。
   ALCOMへ表情ファイルを登録する操作ではありません。ALCOMは実験版の導入に使います。
3. FaceEmo等に登録されたファイルは「候補ファイル」に出ます。必要なファイルの「追加」を押せます。
   推薦は対象アバター・FaceEmo登録が実際に参照するクリップから取得し、名前だけで推測しません。
   クリップに表情カーブがあることは、メニュー全体と同じ顔になる保証ではありません。
4. 追加すると対応可能なファイルは自動でプレビューします。「この表情をプレビュー」で再確認できます。
   動くクリップは「収録する秒」で好きな時刻を選び、その時刻の固定の顔を記録します。クリップの動き全体の保存ではありません。
5. 必要な項目にチェックを入れ「選択した N 表情を記録」を押します。「表情名」は編集できます。
   基準と同じ顔も名前付きで記録でき、最大64件です。同名の登録済み項目は省略します。
   不正なファイルを含む一括処理は途中まで記録せず、元のプレビューも保持します。
6. 「4. 記録した表情を確認・書き出す」の一覧の「確認」で記録した顔を試し、
   「基準の顔に戻す」で解除後の顔を確認します。

### 基準の顔と対応範囲

最初の基準は、元アバターの現在の顔をMA／NDMFで準備した状態です。FX全体は再生しません。
指定クリップが書き込まない変形は毎回この基準から補い、直前に試した別の顔の値を引き継ぎません。
通常顔のファイルや手動調整を基準にする場合は、それをプレビューした後、
「BlendShapeの手動調整・基準の顔（詳細）」の「プレビュー中の顔を基準にする」を押します。
基準を変更すると、登録済みの顔の書き出し差分は新しい基準から作られます。

この版の表情ファイルは、表示中の書き出し対象SkinnedMeshRendererのBlendShapeカーブに対応します。
元メッシュの参照をMA／NDMFの準備後Rendererへ対応付けます。曖昧な統合・分割、欠けたメッシュや変形名は理由を表示します。
材質・画像の差し替え、顔ボーン、表示切替、Animation Eventを含むファイルは「追加対応が必要」と理由を表示します。
形状だけを部分採用して成功とすることはありません。項目を削除するか、対応する別の表情ファイルを選んでください。
複数クリップの合成・BlendTree・Controllerの重みや共通設定が必要な顔は、単一クリップと異なることがあります。
プレビューで確認してください。「従来のメニューから自動取込（詳細）」は引き続き使用できますが、
表情以外のしっぽ等の差分による取得不可の判定はこの経路に残っています。
表情ファイルの明示指定にはそのAnimator再生・差分判定は入りません。

## 全身ポーズを同梱する（任意）

1. Projectからポーズの `.anim` を「3. 全身ポーズを同梱する」の枠へドロップします。
2. 「ポーズのプレビュー・開始秒を確認」で別ウィンドウを開き、対象と時刻を確認します。
   静止ポーズは採用秒、動くポーズは開始秒から末尾までを、既存のポーズ仕様に従って同梱します。
   頭・首は動くクリップに明示指定がある場合だけ対象です。眼・顎・表情用ボーンの一般的な変換ではありません。
3. 対応しないポーズは理由を表示し、選択したポーズの失敗時はVRM保存を止めます。
   ポーズを同梱しなくても表情だけを書き出せます。

表情と全身ポーズは別々に選べるデータとして同じVRMへ保存します。
同時に呼び出す表情＋ポーズのプリセット機能は、この版には追加していません。

## 保存と書き出し

- 「記録設定を保存」でJSONを保存してからウィンドウを閉じてください。
  記録した顔・基準の顔・ポーズの元ファイル参照と時刻を保存します。未記録の表情入力欄は保存対象外です。
  同じ準備後メッシュなら設定を読み戻せます。ポーズの元ファイルは同じUnityプロジェクトのGUIDとファイルIDで解決し、
  見つからない場合は既存の記録を変更せず拒否します。別PCへは元のUnityプロジェクトと設定を一緒に移してください。
- 作者名を入力し、1件以上の表情を記録して「記録した表情をlilToon VRMへ書き出す」を押します。
  瞬きの自動設定ができない場合は「瞬きを自動設定する」をOFFにして試せます。
- VRMのカスタム表情名は **VRChat / 記録 / 表情名** です。ON／OFFで切り替える固定表情として保存し、
  選択中は瞬き・口パク・視線の追加を抑制します。
- 元アバターを編集中に変更した場合は、設定を保存してコピーを作り直してください。
  保存失敗時は既存ファイルを保持します。

検証範囲は同梱の検証結果を参照してください。アプリでの受入と、使用するファイルの最終的な見た目は手元で確認してください。
実験版の公開リリース・mainへの統合は行っていません。
