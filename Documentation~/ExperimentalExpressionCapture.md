# 表情・ポーズ指定版を手元で試す

非公開のALCOM用ユーザーパッケージ **0.11.14-expression-capture.4** です。
安定版として使うためのUIとQR転送を確認する試験用ZIPです。正式公開版は更新していません。
アバター・表情ファイルの原本は変更せず、準備したコピーに指定ファイルを適用します。

## ALCOMで導入する

1. ALCOMで普段のアバタープロジェクトを複製し、そのUnityを閉じます。
2. ZIPをすべて展開します。ALCOMの「パッケージ」→「ユーザーパッケージ」→「パッケージを登録」で、**package.jsonが直接入っているcom.vrvlog.liltoon-vrm-exporterフォルダー**を選びます。
3. プレリリースを表示する設定をONにします。複製プロジェクトの「管理」で **0.11.14-expression-capture.4** を明示的に選び、変更を適用します。同じパッケージIDの通常版と置き換わります。AssetsとPackagesへ重複導入しないでください。
4. Unityで **VR Vlog → 表情・ポーズを指定して書き出す** を開きます。通常の書き出し画面にも入口があります。以前の「実験」メニューは同じ画面を開きます。

前のZIPを登録済みでも、今回のZIPを別フォルダーに展開して新しいフォルダーを登録してください。ALCOMの「インストール済み」が上記の版になっていることを確認します。
Unity Package Managerの「Add package from disk」で同じpackage.jsonを指定する方法もあります。
ALCOMに読み込ませるのはExporterパッケージです。表情・ポーズの.animはUnityのProjectから選びます。

## ① アバターを指定

Hierarchyのアバターの一番上のオブジェクトを「アバター」欄へ入れ、**このアバターの表情を準備**を押します。
基準の顔は現在のアバターをMA／NDMFで準備した状態です。無関係なFX・しっぽ等の再生は表情ファイルの読み込みに入りません。

## ② 表情を確認

1. UnityのProjectから表情の **.anim** を「表情」の枠へドロップします。複数選択も可能です。
   FaceEmo等に登録したファイルは候補一覧の **追加** でも指定できます。候補はアバターが実際に参照するクリップで、名前だけの推測はしません。
2. 対応する表情にはチェックが入り、追加直後にプレビューします。**この表情をプレビュー**で再確認すると画面上部の顔へ戻ります。
3. **表情名**は変更できます。動くクリップは **収録する秒**で選んだ瞬間を固定の顔として保存します。
4. チェックしたファイルを保存時にまとめて記録します。先に記録する必要はありません。
   **選択した表情を記録・更新（確認用）**を押せば、保存前に記録済み一覧でも確認できます。
   名前・時刻を編集すると次の記録／保存で更新し、チェックを外したファイルの記録は次の保存から除外します。
   手動記録や設定から読み込んだ顔は別に保持します。同名の表情は別の名前にしてから保存してください。

プレビューを解除するには **基準の顔に戻す** を押します。

### グレー表示・未対応の理由

- 候補の「追加済み」は、すでに表情欄へ入っているため再追加できません。
- 未対応の表情は項目の **保存できない理由** を確認してください。チェックを無効にして、部分採用による欠落を防ぎます。
- Playモード中は編集できません。Playモードを終了してください。
- 保存ボタンは表情0件・作者名未入力・不正な選択の場合に無効になり、その理由を近くに表示します。

対応するのは、書き出すSkinnedMeshRendererのBlendShapeカーブです。材質・画像の差し替え、顔ボーン、表示切替、Animation Event、曖昧なメッシュ統合や欠けた変形には未対応です。
指定しない変形は毎回基準の顔から補います。直前のプレビューの値を引き継ぎません。
基準と同じ顔も名前付きで保存でき、最大64件です。不正な一括更新は途中まで反映しません。
複数クリップの合成・BlendTree・Controllerの重みや共通設定が必要な顔は、単一クリップと異なることがあります。

全身ポーズは **全身ポーズを追加（任意）** を開き、別の枠へ.animをドロップします。
**ポーズのプレビュー・開始秒を確認**で対象と時刻を確認できます。表情とポーズは別々に選べるデータとして同じVRMに同梱します。
静止／動くポーズは既存のポーズ仕様を使用し、同時に呼び出す表情＋ポーズのプリセット機能は追加していません。
顔の手動調整、基準の顔の変更、従来の自動取込は詳細の折りたたみ内にあります。従来の自動取込にはしっぽ等の差分による取得不可が残ります。

## ③ 保存・QR転送

1. **作者名（必須）**とライセンスを元の規約に合わせて設定します。
2. **表情を記録してVRMを保存**を押して保存先を選びます。記録した表情と任意のポーズを含むlilToon VRMを書き出します。
3. 保存完了欄の **QRコードでスマホに送る**を押します。完成済みVRMの転送用コピーを作り、転送画面を開きます。この操作だけではアップロードしません。
4. 転送画面で一時保存の説明を確認し、**アップロードしてQRを表示**を押します。
5. QR受信に対応するiPhone版VR Vlogで **モデルを変更 → PCから受け取る**を開き、アプリ内カメラで読み取ります。PCとiPhoneの両方にインターネット接続が必要です。Android配布版のQR受信は無効です。

完成済みVRMをPCで暗号化してからクラウドへ一時保存します。復号鍵はQRに含め、サービスへは送りません。
上限は256 MiB、受取期限は転送作成から3分です。アップロード中も期限が進み、完了・中止・期限切れで転送用コピーを削除します。
QRを持つ人は受け取れるため共有・撮影しないでください。画面を閉じると転送用の一時コピーを片付け、保存した元VRMは保持します。
詳細は同梱の[QR転送ガイド](CloudTransfer.md)を参照してください。

QRで送るのは **最後に保存したVRM** です。表情やポーズを編集したら再び保存してください。
保存先のVRMが移動・上書きされた場合は、別の内容を送らず再保存を案内します。

## 設定と再試行

「記録済みの表情・設定の保存」を開き、**設定を保存**で基準の顔・記録済み表情・ポーズ参照をJSONへ保存できます。設定を読み込むとファイル入力欄は置き換わり、読み込んだ顔を記録一覧で確認できます。
表情ファイル入力欄そのものや作者名・ライセンスはJSONに保存しません。

元アバターや参照アセットが変わって準備状態が失効した場合は設定を保存し、詳細の **コピーを作り直す** から再準備してください。
書き出し失敗時は既存の保存済みVRMを保持します。瞬きの自動設定が解決できない場合はOFFにして固定表情を試せます。
通常版へ戻すときはUnityを閉じ、ALCOMの「管理」で公開中の通常版を選びます。

このZIPにはアバター本体・私有画像・テスト用VRMは含みません。検証範囲はZIP直下の検証結果.mdを参照してください。
